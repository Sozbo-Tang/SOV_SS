## 2. 部署 / 购买界面

### 2.1 战斗内部署菜单（购买流程）

官方截图：PDF 第 4 页右栏部署面板条（提取件 `deploy_panel.png`）【手册】P6-7：

```
┌─部署菜单（点左上部署点图标展开）──────────────────────────────────┐
│ 类别页签: LOG │ INF │ SUP │ TNK │ REC │ VHC │ HEL │ AIR │ NAV    │
│ 单位卡: [照片][+购买]  [照片][+] …   卡角: (N)=可用数量          │
└────────────────────────────────────────────────────────────────┘
```

- 流程：左键部署点图标 → 左键类别页签 → 左键单位卡购买 → 左键地面放置；**右键取消购买**（部署阶段右键地上单位=连买带放一起取消；对机场面板飞机同样有效）【手册】P6-7。
- **Ctrl+左键**一次买整排（如 4 步兵班、2 直升机）；**按住 Shift 放置可克隆**该编组连续部署【手册】P6-7。
- 单位点值取决于**类型与经验档**；开局点数由任务/房间设置决定，未用完的点数带入开战后；夺取带入口的指挥区后全场随时可续买【手册】P6-7。
- 飞机照常购买但不落场，入机场面板 9 机位，开战后经 `AIR COMM` 派"任务"进场；双击机场面板图标开启跟随镜头（Follow cam）【手册】P6-7、P14-15。
- 海军舰船仅在有海上增援区的地图可买（NAV 页签，舰船卡不占激活点）【手册】P6-7、P12-13、P28-29。

### 2.2 牌组（Deck）编辑器——单位卡信息字段

官方截图：PDF 第 15-16 页两张标注图（提取件 `deck_select.png`、`deck_units.png`）【手册】P28-31：

- **建牌对话框**字段：`DECK NAME`（命名）/ `FACTION`（BLUFOR/REDFOR，两侧不可混编）/ `NATIONAL/COALITION DECK`（国家或联军）/ `TYPE`（专精类型）/ `ERA`（年代限定）；`Create/Cancel`。新手 Starter 牌组显示为白色，不可删改但可复制【手册】P30-31。
- **编辑器界面**编号字段：①所选单位类别 ②筛选器（按时代/主题/角色等多参数）③牌组名 ④已用/总激活点（如 `ACTIVATION POINTS: 914/9××`）⑤已入牌组单位（Delete 移除）⑥**所选单位的可用经验档位——"同价但可用度不同"** ⑦可加入的候选单位；左侧类别栏标注单位数（如 40 UNITS）与每类已花激活点【手册】P30-31。
- 限制换收益：限单国/联军→解锁原型车+全国可用度加成；限单一类型→单位经验更高+更低成本扩格；限旧年代→返还更多激活点；海军单位 0 激活点【手册】P28-31。
- 牌组可**导出为文本串分享**【手册】P30-31。
- **经验（veterancy）五档**：Rookie / Trained / Hardened / Veteran / Elite。手册只写"档同价、可用度不同"（P30-31）；社区 wiki 给出精度倍率 100/110/126/136/160%，且 veterancy 只作用于"人"（瞄准/装填/精度/侦查/抗性），不改变装甲与火力【社区】https://wargame.fandom.com/wiki/Morale_and_Veterancy 。

## 3. 战斗中反馈

### 3.1 选中单位面板（底部中央）9 要素

官方截图：PDF 第 5 页（提取件 `unitpanel_big.png`，示例 M1A1(HA) Abrams）【手册】P8-9：

```
┌─单位面板────────────────────────────────────────────────────┐
│ [2]军衔徽章 ^  [1]指挥官名"Spear"  [3]经验进度(分段条,橙=进度) │
│ [4]状态/完好度条(青色分段)  [5]CALM  [6]油料 2000/2000        │
│ [8]武器1 [M256 OFF][25/25][120mm] [9]武器2 [M2 Browning ON]  │
│           [900/900][12,7mm]   [M240 ON][4400/4400][7,62mm]   │
│ [7]型号全宽条: M1A1(HA) ABRAMS                               │
└─────────────────────────────────────────────────────────────┘
```

1. 指挥官姓名 2. 军衔（打仗攒经验：命中/装填/瞄准/侦查/士气全面变好）3. 升衔经验进度条 4. 完好度条（空=被毁）5. **士气状态** 6. 油料 7. 型号名 8/9. 武器卡（最多 3 挺）：图标+**ON/OFF 开关**（点卡=停用/启用该武器）、弹药余量/容量、口径【手册】P8-9。

**士气 5 状态**：Calm（从命）→ Worried（受扰，精度/装填略降）→ Panicked（精度/装填剧降）→ Stunned（暂时瘫痪无反应）→ Rout（溃逃，**不可下达命令**）【手册】P8-9。社区数值手册补充机制：压制为隐藏数值（全员初始 0、上限 800），**1 秒内累计 300 压制即眩晕 8 秒**（无法行动并打断当前动作），眩晕时长随老练度递减（Rookie 8 秒 → Veteran 3.2 秒 → Elite 1.6 秒）【社区】ResidentMario 数值手册 Morale 章节（与 03 §8 同源同值）。（勘误：本节早期版本曾记「5 秒内压制值超 300 会眩晕 3 秒失控、离开战场 30 秒开始恢复」并标注出处 Fandom Morale and Veterancy——经 2026-10-13 取回该页现文核对并无此数值，该口径弃用；两社区源冲突统一取基于游戏文件逆向的 ResidentMario 数值手册，见 03 §8 冲突注。）

### 3.2 按 I 的单位信息面板（详细字段）

官方截图：PDF 第 6 页 M1A1 Abrams 全参数面板【手册】P10-13：武器三栏并列，各栏含弹药型号与备弹（120mm rounds ×25…）、对地/对直升机/对固定翼**三行射程**（不可用则灰）、ACCURACY、STABILIZER、AP POWER、HE POWER、SUPPRESSION、RATE OF FIRE；ARMOR 区 3D 模型 + 前/侧/后/顶四向装甲条；GENERAL 区：Strength（班兵力/HP）、Size（越大越易被命中）、Optics、Speed/Road Speed、Stealth、Fuel Capacity、Autonomy、Stabilizer、Year、Type。**特性值用色分级：红=低、橙=中、绿=好、蓝=极优**；悬停面板任一元素弹出详释【手册】P10-13。

**三行射程的官方示例**（手册配文，M1A1 Abrams）【手册】P12-13：M68 坦克炮对地面 1925m、M2 Browning 对地面 1050m；对直升机仅 M2 可用（875m）；**对固定翼两武器均无**（面板该行灰显）——"三行射程"是每件武器逐行标定、不可用即灰的呈现。

**GENERAL 区字段官方释义表**（【手册】P12-13 逐条；为 SOV_SS 属性面板字段命名提供一手对照）：

| 字段 | 官方释义 |
|---|---|
| Strength | 班组成员数或 hit points 数 |
| Size | 单位体积，越大越易被命中 |
| Optics | 光学越好越易发现敌军 |
| Speed / Road Speed | 越野速度 / 公路速度 |
| Stealth | 隐蔽越高越难被敌方发现 |
| Fuel Capacity | 加满油箱所需的燃料量 |
| Autonomy | 满油续航里程（km） |
| Stabilizer | 稳定器越好，行进间射击越准 |
| Year | 单位投产年份 |
| Type | 单位所属战斗群类型 |

### 3.3 命中/击杀事件流与开火指示

- **瞄准线（Line of fire）**：发现敌人后自动开始瞄准，鼠标悬停敌单位显示"瞄准图标+视线"两段线：白实线（有效射程内可杀伤）/ 白半透明（在视线内但超出射程）/ 白点线（视线被挡或超射程；三态命名与 03 §5 统一，手册原文为 white opaque/transparent/dotted line）。**瞄准图标变红=不能开火**，并以文字标注原因：`INVALID TARGET`（武器不适用）、`OUT OF RANGE`、`NO LINE OF SIGHT`、`INEFFICIENT`（够得着但穿深不足）——截图见提取件 `los_shot.png`【手册】P8-9；`INEFFICIENT` 触发时单位会自动尝试拉近距离【社区】https://wargame.fandom.com/wiki/Damage 。
- **战果反馈**：手册记载的重创（critical hit）橙色图标为 Embedded 反馈；wiki 列出带计时的战损条目（稳定器故障、油箱漏油、弹药殉爆、涡轮故障等）【社区】Damage 条目。**屏幕侧边kill feed/击杀滚动栏：手册与 wiki 均无记载，未能核实**（红龙无此类官方描述；击毁反馈以目标图标消失/残骸呈现为主——残骸呈现方式亦未见官方文字，未能核实）。
- 炮兵可无视线开火，有友军视线时自动校射；火箭炮对士气伤害更高【手册】P18-19。

## 4. 视野呈现

- **无战争迷雾**：地形全图可见（相机可任意巡视规划）；但**敌方单位只有进入我方任一单位视线后才显示**【手册】P8-9。
- **灰色/黑色"疑似"目标**：已发现但未识别的敌单位显示为**黑色"幽灵"轮廓**，需玩家凭轮廓自行判型；对应标签 `Unidentified Unit`【手册】P6-7、P18-19。
- **无线电共享**：一单位发现的敌人全军皆见（现代无线电模拟）【手册】P8-9。
- 侦查单位光学更强，**发现小/隐蔽目标更快**，识别已定位目标也更快、更不显眼【手册】P8-9、P16-17。
- 识别速度与距离由 `Optics`（越好越易发现敌军）与目标 `Stealth`（越高越难被发现）共同决定，两参数都在信息面板以色阶呈现【手册】P10-13。
- 地形影响视线：建筑挡视线，树篱/树丛降质；制高点增益【手册】P6-7。

## 5. 相机

## 7. 回放与观战 UI（简要）

- **官方手册全篇无"replay/observer/spectator"任何记载**（目录与正文均无）；仅有战役模式在每场战斗开始/结束时自动存档、战斗中可经暂停菜单手动存档的说明【手册】P24-25。
- 社区佐证功能缺失：Steam 讨论区 2014-03 "spectator mode" 帖请求加入观战模式（"woud love to see put into the game… for doing a few torneys and such for streaming"）；2015-02 "Replays?" 帖询问"Does Wargame have a record replay feature?"——两者均表明发售初年无内建观战/录制回放【社区】steamcommunity.com/app/251070/discussions（"spectator mode"、"Replays?" 两帖，经检索快照确认存在）。赛事转播实际做法为选手 POV 直播/录屏（未能核实更权威的一手描述）。

## 8. 颜色与图标语言

### 8.1 阵营配色

- **BLUFOR=蓝、REDFOR=红**：战略地图区域按控制方着蓝/红【手册】P20-21；多人大厅出生点位"在红/蓝区随机"【手册】P26-27；战斗中已控制区以本队颜色着色【手册】P4-5。

### 8.2 兵种图标与角标

- 图标风格二选一：**RTS 写实风 / NATO 军标风**；标签样式三选一（RD/EE/自定义）【手册】P8-9。
- 单位标签角标 5 种（提取件 `corner_icons2.png`）【手册】P16-17：**★=指挥单位**；油桶=补给单位；**双筒望远镜=侦查单位**；交叉手枪徽=精锐班；**火焰=燃烧武器单位**。
- 9 大类别及缩写（部署页签同源）：LOG 后勤 / REC 侦查 / TNK 坦克 / INF 步兵 / SUP 支援（炮兵+防空）/ VHC 载具 / HEL 直升机 / AIR 固定翼 / NAV 海军【手册】P12-13。
- 标签体系自带语义后缀与组合（如 "Recon Team"、"Light Command Vehicle"、"(Also exists as Recon/Command/Support…)"），同型异种靠角标+名称区分【手册】P16-19。
- **标签术语官方释义选**（手册 P16-19 逐条；呈现层含义＝玩家在标签上读到的词即代表下述能力，机制细则见 03 各节）：

| 标签词 | 官方释义要点 |
|---|---|
| Recon Team | 侦察范围大于普通单位、可更快识别已定位目标、比一线单位更不显眼 |
| FOB | 存储大量补给的受保护设施，**只能部署阶段放置** |
| Light/Armored Command Vehicle | 夺区收点的轻/重指挥载具，**必须静止生效**（另有 Recon/Supply/Vehicle 变体） |
| Command Helicopter | 可夺区的直升机，较脆弱但机动抢占前沿 |
| Command Infantry | 可夺区且能进楼驻守，**须先下车** |
| Supply Vehicle | 送油送弹、修车补员；**从不抛锚，但可能被敌缴获** |
| Transport Helicopter | **必须落地**才能装卸部队 |
| Artillery | 可越障碍超视距射击，友军通视时可校射；典型有最小射程（个别新榴弹炮可平射） |
| Multiple Rocket Launcher | 齐射快、伤害低于火炮**但士气伤害更高**、耗弹大、有最小射程 |
| Unidentified Unit | 已被发现但未识别的敌单位标签 |

### 8.3 指令图标/按钮形态学

- 基础命令为**文字按钮**（ATTACK / STOP / FIRE POS / MOVE FAST / REGROUP / DISPLAY FORMATIONS），分 `BASE ORDERS` 与 `ADVANCED ORDERS` 两层【手册】P6-7 截图、P32-33。
- 武器开关是**武器剪影卡 + ON（绿）/OFF（红）角标**【手册】P8-9 截图。
- 状态语义色：**橙色=危急**（重创/重压/溃逃/缺油四枚橙图标）【手册】P10-11；特性分级**红→橙→绿→蓝**由劣到优【手册】P12-13；瞄准禁止用**红色**瞄准图标+文字原因【手册】P8-9。
- 进场箭头形态语义：细长=空中/海上，短宽=地面【手册】P4-5。
- **进驻建筑的呈现**：步兵下车进驻建筑时，**其驻扎的街区（district）以蓝色高亮**标示，载具留在外面【手册】P16-17（INFANTRY MANAGEMENT）。
- **9 大类别官方角色定义**（部署页签与标签体系的语义底座）【手册】P12-13：LOG＝补给与指挥单位；REC＝优势光学＋受训索敌；TNK＝主突击力量；INF＝随陆地/空中载具进场、UNLOAD 卸载；SUP＝炮兵＋防空；VHC＝轻快低价载具；HEL＝高机动大视线（炮艇/防空/运输等特化）；AIR＝买而不落场、经左下 Air Comm 派"任务"；NAV＝反舰/登陆等，仅限有海上增援区的地图。

## 9. 战役模式界面（战略地图）（本次扩写新增）

> 手册 CAMPAIGN MODE 章的界面面；机制面见 03 §2.1。

- **战略地图主层**：地图分区着蓝/红表示控制方；左上为**政治点**（Political Points，用法同战斗内部署点）；区名旁数字＝该区每回合政治点产出；**主目标/次目标**（primary/secondary objectives）在图上标出——主目标必须保住才获胜，次目标决定胜利大小【手册】P20-23。
- **BG 信息面板 6 字段**：①战斗群名 ②Cohesion ③Morale ④Initiative ⑤可用单位数 ⑥单位清单【手册】P22-23。
- **基础设施层**：机场（买机队驻场、可 Refit；**被占则驻场机队全灭**）、港口（买陆上 BG、Refit、装卸海运）、海上修理点、航线（海军 BG 驻场与修理）【手册】P22-23。
- **战斗预告层**：开战前标示敌方需达成的 Destruction points 目标线；战斗以四种结果文案结算（Total/Major/Minor victory-defeat、Tie），另有 20 分钟强制平局规则【手册】P24-25（机制见 03 §2.1）。
- **存档呈现**：战役在每场战斗开始/结束自动存档；战斗中可经暂停菜单手动存档【手册】P24-25（§7 已引，与回放/观战功能无关）。

## 10. 多人大厅与 Skirmish 界面（本次扩写新增）

- **入口**：左下「Multi」按钮→会话列表（等待玩家的对局）→选中后点面板底部「Join」；建房点「Create」【手册】P25-26。
- **建房对话框字段**：Game type（人数规模，后可改）/ Game visibility（**Private**=不出现在列表、只能邀请进入）/ Game name【手册】P25-26。
- **卡组限制提示**：房规可强制 National/Coalition/Themed/Period 卡组类型；受限时**必须同时持有匹配的 BLUFOR 与 REDFOR 卡组各一套**才能建房与加入【手册】P25-26（与 03 §1 卡组规则互证）。
- **房间设置层**：地图选择（**可选图与人数挂钩**，预览功能可查看地形、指挥区位置与产值、起始区）；对抗方式三选（BLUFOR 全员蓝 / REDFOR 全员红 / Confrontation 自选）；`gain speed`（指挥点增速，越高铺场越快）；出生点位"在红/蓝区随机"【手册】P26-27。
- **Skirmish 界面**：从 SOLO 菜单进入，**无需登录 Eugen.net**；1v1–4v4、可选 AI 等级；胜利条件与多人一致【手册】P28。
- **行为规则入口**：多人游戏内公示行为守则（禁辱骂/仇恨言论/队杀等），违规者 EugeNet 账号临时或永久封禁【手册】P27。
