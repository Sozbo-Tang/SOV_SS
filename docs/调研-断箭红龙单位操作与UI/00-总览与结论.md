# 00 · 总览与结论

> 本篇为「断箭（Broken Arrow, 2025）× 红龙（Wargame: Red Dragon, 2014）单位操作与 UI 调研」的总览与汇总结论。
> 铁律：逐条结论均出自 01~04 四章，行内以（章·节）标注出处；各章内已自行标注【手册】/【官方指南】/【社区】分级，本篇仅在关键处重复提示，不引入四章之外的新事实。
> 成稿日期：2026-10-13。

## 1. 调研范围与方法

- **对象**：断箭（Steel Balalaika 开发，Slitherine 发行，2025-06 发售）与红龙（Eugen Systems 开发，Focus 发行，2014-04 发售）两作的单位操作机制与 UI 界面呈现。（01 头注；03 头注；04 头注）

- **来源分级**：【手册】（官方手册原文，一手权威）＞【官方指南】（官方渠道非手册指南；断箭为 Open Beta 期文档，红龙本次未获得）＞【社区】（Steam 指南/讨论/实机截图、社区数值手册，二手交叉印证）。冲突时以手册为准。（01 头注；02 头注；03 §0；04 头注）
- **材料形态**：断箭＝官方手册 28 页全文＋官方多人 Beta 基础指南＋本地实机截图 4 张与社区截图互证（01 头注；02 头注）；红龙＝官方手册 20 页 PDF（经 GitHub 存档获取，附获取路径记录；印刷版页码与 PDF 页码换算：**印刷 P2N-2~P2N-1 ≈ PDF 第 N 页**，如 PDF p.17＝印 P32-33，03 章按 PDF 页、04 章按印刷页标注，可据此互换）＋ SandyGunfox 社区指南＋ ResidentMario 数值/内部数值手册＋ Fandom wiki 部分条目（经 webReader 阅读器通道取回，见下条与 04 附C）；Steam 实机截图不可达，改用手册内嵌官方标注截图提取件（03 §0/§12；04 头注/附C）。

- **对照用途**：四章事实面统一汇入 05 章的逐维度对照表与 SOV_SS 启示清单；本篇是阅读 01~04 与 05 之间的索引层。（05 章头注）

## 2. 断箭·操作机制核心结论

1. 命令热键成体系且全部可改：Q 攻击移动、E 取消所选单位全部命令、H 停火（受击才还击）、F 快行军（走公路）、R 倒车、U 卸载（手册：连按两次立即原地卸；社区另记双击 U＝等当前命令完成后才卸，两源冲突见 01 §6.2）、B 返航退款、T 炮击、O 空投、V 高度。（01 §0/§2/§3/§6/§8，【手册】p.19–24）
2. Z 键按单位类型三重复用：步兵＝冲刺（双倍速、有充能、冲刺中不能行进间射击）、战机＝加力（双倍速、油耗翻倍）、雷达车辆＝雷达开关。（01 §0/§2.4/§2.5/§4）
3. 移动语义三分：普通移动考虑掩体、Fast Move 无视掩体并利用公路提速、倒车保持正面装甲朝敌避免暴露轻装甲。（01 §2.1–2.3）
4. 多单位控制三件套：TAB 子选择（不丢大选区把命令只给一个单位）、CTRL+1–9 编组、SHIFT 排队命令（部署指令亦可排队）。（01 §1.2–1.4）
5. 开火控制＝自动优选＋停火模式：武器自动按「对目标伤害最大化」选择；H 停火仍保持瞄准、解除即射；步兵轻反坦克武器（AT4/RPG）命中载具必触发战损效应；强制开火可对未发现敌人的可疑建筑开火。（01 §3.2–3.4）
6. 炮击 Fire Mission（T）三参数正交：弹药（高爆/烟幕/精确）×时长（短/中/长）×弹道（Point/Line/Walking 徐进）；超射程炮兵自动机动到最大射程再开火；弹道有问题整条红色高亮并文字标注。（01 §5.2–5.5）
7. 激光链路自成闭环：N 照射（激光跟随移动目标、离视线即断）→ Precision 弹种或 P 精密打击命中照射点附近区域；可 Shift 排队多点打击。（01 §4/§5.6）
8. 防御能力键化且可自动化：烟雾 X、干扰弹 C 被导弹锁定时自动触发；APS 全自动拦截有冷却；雷达默认关，开机显著增加视野射程但暴露给反辐射导弹。（01 §4）
9. 呼援经济三轨：黄＝点数储备、白＝收入（每秒结算）、upkeep（场上部署总价值达 deck 总价值 50% 时收入归零）；被毁单位过段时间回卡、回卡前照付维护费；B 返航按损伤与耗弹折价退款（Beta 口径下限 20%）——循环经济。（01 §7.2/§8.5）
10. 士气/压制与战斗内经验在官方文本中近乎空白（仅三处间接证据；**官方文本内数值未能核实**，社区口径的具体数值见 02 §8）；成文的状态系统是战损效应：黄（轻）/红（重）两级 × 瞄准/探测/装填/机动四类，修满即消除。（01 §9）

## 3. 断箭·UI 核心结论

1. HUD 五区范式：左上增援点数（黄大数＋白收入小数）、左缘六页签呼援轨（REC/INF/VEH/SUP/HEL/AIR）、顶中计分板、左下小地图＋通信标记 4 钮＋编组列、右下选中状态面板＋命令圆钮。（02 §1）
2. 命令菜单位置官方明文「对局画面右下角」，按钮随单位类型变化、与热键一一对应。（02 §1/§4，【手册】P18/P22）
3. 单位标签＝下尖五边形铭牌：半透明黑底＋兵种剪影（颜色随所属玩家）＋顶部血条＋底部人数（当前/满编）＋8 要素状态小图标。（02 §8）
4. 选中反馈双层：底部多选摘要行（每张小卡＝剪影＋弹药余量计数）＋右下状态主卡（武器清单分行带 x/y 余量、瞄准/装填滑标、HP 条）；TAB 子选不丢整组选择。（02 §3）
5. 命令反馈偏地图层：炮击弹道红色高亮＋问题文字、单位图标白（瞄准）→红（开火）、激光制导弹目红色连线、按住 Alt 显示视线（LoS）工具。（02 §4）
6. 敌我配色：己方＋盟军＝绿色系（按玩家分深浅）、敌方＝统一红色；支持逐玩家改色并可导入导出配色方案。（02 §7/§8）
7. 部署购买反馈：部署区以发光描边表示（蓝/青己方、粉/红敌方）；下单后「幽灵」半透明模型 1–2 秒实体化、扣点实体化前可右键取消。（02 §2）
8. 士气以标签色闪呈现三态：正常→紧张 Stress（橙闪）→恐慌 Panic（红闪），并附具体惩罚数值（车辆瞄准 −25%/−50% 等）。（02 §8）

## 4. 红龙·操作机制核心结论

1. 四种移动命令：Move（右键）、Move and Attack（Q，进射程遇敌停车接战）、Move Fast（;，沿公路最快且**不停车接战**）、Reverse（G，正面朝敌倒车、慢于前进）；Shift 排队列命令。（03 §4）
2. 开火控制粒度到武器：右键点敌攻击、T＝Fire on Position（圈标即散布半径、可对不可见目标盲射/打烟）、E＝Stop 停止并清令、每单位最多 3 种武器各自 ON/OFF 独立开关。（03 §5）
3. 火力线三态＋禁射四原因：白实线（不透明白线：有效射程内，可开火杀伤）/白半透明线（目标在视线内但超出射程）/白点线（视线被挡或目标超射程）；瞄准图标变红并标注 INVALID TARGET / OUT OF RANGE / NO LINE OF SIGHT / INEFFICIENT。（03 §5；04 §3.3）
4. 编队 Squad 系统：R 并队、按住 X 点地拆成单车、Spread 拉开间距；双击数字键镜头跳到该编组、空格跳至最近事件。（03 §3）
5. 经济＝占区产出：CV 指挥单位开进指挥区并**停车**才有收入（4 秒节拍到账）；Conquest 模式收入固定不随占区变化；呼援前提是本队控制至少一个带增援入口的指挥区。（03 §2/§6）
6. 后勤＝FOB＋补给车网络：弹药/油料/维修共享同一补给池、可分项开关；补给车不耗油但会被敌人缴获、被毁殉爆波及邻车；空车回 FOB 重载再上前线是标准循环。（03 §7）
7. 士气五态＋隐藏压制值：Calm→Worried→Panicked→Stunned→Rout（Rout 无法下达任何命令）；压制值 0–800 按 0/200/400/600 分段；老练度五星「同价不同量」（星级越高每卡数量越少）、战斗内每秒 +0.1/击杀 +2.5 涨经验。（03 §1/§8）
8. 无战争迷雾：地形全图可见，敌单位进入己方任一单位视线才显示；已见未识别＝黑色「幽灵」剪影；无线电组网使全军共享视野。（03 §9；04 §4）
9. 飞机＝机场面板资源：9 机位三状态（可用/任务中/加油中），开战后经 AIR COMM 派任务；自动 RTB 双触发（油尽 Bingo/弹尽 Winchester）；无油量表、以滞空时间计量；每张卡即一个固定挂载（社区资料转述，手册未明文）；直升机三档高度、悬停不耗油。（03 §9/§10；04 §2.1）
10. 无独立「保持位置」键（由 Stop＋武器开关组合实现的缺席推断）；敌方补给车己方单位不会自动射击、需手动下令。（03 §5）

## 5. 红龙·UI 核心结论

1. 官方手册按「卫星视角 10 区＋地面视角 9 区」两组编号讲解界面，配官方标注截图。（04 §1）
2. 布局范式：左上部署点/收入、右上小地图（可直接在图上下令＋左键跳转相机）、小地图正下方计时＋两队分玩家比分、底部中央选中单位面板、右下指令面板（BASE ORDERS 与 ADVANCED ORDERS 两层文字按钮）、左下 HQ/CHAT/AIR COMM 与左中 9 格机场面板。（04 §1）
3. 选中单位面板 9 要素：指挥官名/军衔/升衔经验条/完好度条/士气状态/油料/型号名/武器卡（带 ON 绿 OFF 红角标＋弹药余量/口径）。（04 §3.1）
4. 按 I 的详细信息面板：对地/对直升机/对固定翼三行射程、前侧后顶四向装甲条、特性值红→橙→绿→蓝色阶分级、悬停任一元素弹详释。（04 §3.2）
5. 图标语言可切换：单位图标 RTS 写实/NATO 军标二选一、标签样式三选；单位角标 5 种（★指挥/油桶补给/望远镜侦察/手枪精锐/火焰燃烧）。（04 §6/§8.2）
6. 状态语义色：橙＝危急（重创/重压/溃逃/缺油四枚橙图标）；特性分级红（劣）→橙→绿→蓝（极优）。（04 §1.3/§8.3）
7. 击杀 feed 与回放/观战 UI 均无官方记载（社区帖佐证发售初年无内建观战/回放）。（04 §3.3/§7）

## 6. 重要的未决问题（各章 gap 汇总）

**断箭操作（01 §11）**

- 框选/加选/减选等选择细节（官方两份文本无文字记载，仅社区实机描述）；
- 攻击移动选择目标的内部优先级权重（仅有「武器按伤害最大化」一条）；
- 压制/士气系统的官方数值与条（仅三处间接证据；社区口径数值见 02 §8）；
- 战斗内经验/老练系统是否存在（账号层进度系统已单列对照，见 01 §9.5）；
- 探测/隐蔽（侦视视野）机制：断箭侧官方定性六因子有载（01 §9.4：光学定基准、隐蔽作除数、掩体减半、林烟衰减、开火与被发现减隐蔽），数值与档位未能核实（01 §11.8）；
- 部署区边界判定规则（何处可部署）；
- 现行经济数值——2026-07 动态收入更新后，Beta 文档数值（收入示例、50% 上限、20% 退款下限）存疑（01 §7.4）；
- Slitherine 官方论坛（登录墙）与 Reddit（403）不可达，相关社区讨论未采集（01 §11.7）。

**断箭 UI（02 未能核实清单）**

- 部署阶段是否隐藏小地图（无部署阶段截图互证）；
- 小地图能否点击直接下令移动；
- 滚轮缩放是连续还是固定档位；有无「跳转至事件」类热键；
- 路径点/航线的具体图形样式；
- 顶中计分区两个辅助计数框逐格语义（社区指南口径推断，非官方）；
- 步兵登车后在标签/面板上的显示方式；
- big_6 截图出现「ФАЗА IV」与社区指南「标准对局 3 阶段」口径不一致（疑似非标准模式阶段数可配，未获官方口径）；
- 血条颜色随血量变化的梯度。

**红龙操作（03 §12）**

- 官方手册仅得 GitHub 存档版，与零售版一致性无官方页面可比对；
- Fandom wiki 直连不可达（webReader 阅读器通道可取回部分条目，见 03 §12 勘正注），Controls 完整键位表未能直接抄录（以手册＋社区指南双源合并替代）；
- 各指挥区收入具体数值（每 4 秒多少点、征服模式固定收入数值）；
- 供给半径具体米数（仅有「黄圈标示」的社区描述）；
- 「双击选屏幕内同类单位」是否存在；
- 飞机呼入时的挂载选择界面一手明文（现为社区资料转述）；
- Reddit r/wargame 与 Eugen 官方论坛不可达。

**红龙 UI（04 附 B）**

- 改键（key rebinding）是否存在及范围；
- 界面缩放（UI scale）与色盲辅助选项；
- 相机俯仰角具体限制；
- 击杀/击毁事件 feed 的具体形态；
- 战后结算/计分屏界面形态（断箭侧对照见 02 §9/§10）；
