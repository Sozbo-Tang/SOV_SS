## 一、合并机制清单

### A. 移动指令与操作

**N01 移动令下达与命令排队（SHIFT）** ✅两源一致（GDD-06 G1/G2/G24）
- 设定：特殊移动令统一为「热键+左键点击」（Q/U/F/R 等）；SHIFT=Queue orders 命令排队（航点链），对编组同样适用；基础移动以右键为基准操作（周年更新设计师注提及 "simple right-click"）。
- 证据：官方手册 ORDERS/热键表〔官方〕；周年更新 FastMove/Reverse 可直接作用于补给箱转为补给令〔官方〕。
- 来源：https://ftp.matrixgames.com/pub/BrokenArrow/BrokenArrowManualEBOOK.pdf ; https://steamcommunity.com/app/1604270/announcements
- 对照：GDD-06 G2/G24 同口径。路A曾标注「右键=移动未在可抓取原文直接出现」，GDD-06 持官方侧证（周年设计师注），采信 GDD-06，不构成分歧。

**N02 攻击移动（Q=Attack Move）** ✅两源一致（GDD-06 G1/G19）
- 设定：直奔目标点，途中遭遇**已发现**敌人停下交战（非边走边打推进）；单位入森林显示掩体指示图标。
- 证据：官方手册 ORDERS 原文〔官方〕。
- 来源：https://ftp.matrixgames.com/pub/BrokenArrow/BrokenArrowManualEBOOK.pdf

**N03 取消令（E=Cancel Order）** ✅两源一致（GDD-06 G1）
- 设定：E 清空所选单位全部命令（通用停止/全清键，非仅停止移动）。
- 证据：官方手册热键表〔官方〕。
- 来源：https://ftp.matrixgames.com/pub/BrokenArrow/BrokenArrowManualEBOOK.pdf

**N04 快速移动（F=Fast Move）：沿路+道路速度档+弃掩体，无独立倍率** ✅两源一致（GDD-06 G4）
- 设定：走最快路线、无视掩护、使用道路（道路显著提速）；数据模型每单位只有路速/越野速两值、无第三个 fast 值→FastMove 是路径偏好切换+吃 Road speed 档，不是乘法 buff。
- 证据：官方手册 + 开发者 FLX 确认「道路满速→越野更慢→森林更慢」（原话见 D1）〔官方〕。
- 来源：https://ftp.matrixgames.com/pub/BrokenArrow/BrokenArrowManualEBOOK.pdf ; https://steamcommunity.com/app/1604270/discussions/0/3275813923400468475

**N05 倒车移动（R=Reverse Move）** ✅两源一致（GDD-06 G3/G5）
- 设定：直线倒车到目标点，保持正面装甲朝敌；独立倒车速度档。官方曾修复 "reverse bug"（双击快速选择后立即下令导致倒车令错位）；patch notes 出现 "validate a fast move or reverse order"（倒车与快移并列为基础移动令）。
- 证据：官方手册 + 官方补丁记录〔官方〕；社区「右键即倒车」仅摘要〔摘要〕。
- 来源：https://ftp.matrixgames.com/pub/BrokenArrow/BrokenArrowManualEBOOK.pdf ; https://store.steampowered.com/news/app/1604270/

**N06 卸载移动（U=Unload）** ✅两源一致（GDD-06 G20）
- 设定：U+左键点地卸载；点建筑则下车进楼；双击 U 立即卸载；1.0.10 起支持拖拽卸载（GDD-06 补充）。
- 证据：官方手册 ORDERS〔官方〕。
- 来源：https://ftp.matrixgames.com/pub/BrokenArrow/BrokenArrowManualEBOOK.pdf

**N07 航点线可视化** ➕联网新证补充（GDD-06 G24 只记拖拽预览线，未记颜色）
- 设定：下令后地图显示航点线，玩家报告白/绿/红三色线；alpha demo 期有航点线异常残留报告。
- 证据：Steam 讨论区帖正文直读〔社区〕。
- 来源：https://steamcommunity.com/app/1604270/discussions/0/819206164467209415/

**N08 编组与子选择（CTRL+1-9 / TAB）** ✅两源一致（GDD-06 G25）
- 设定：CTRL+数字分配编组；TAB 子选择可在不丢整组选中下对单车下令；SHIFT 排队对编组适用。
- 证据：官方手册热键表 + beta 手册界面章〔官方〕。
- 来源：https://ftp.matrixgames.com/pub/BrokenArrow/BrokenArrowManualEBOOK.pdf

**N09 无队形系统（负发现）** ✅两源一致（GDD-06 G14）
- 设定：官方手册无任何 formation 键位/条目；多单位默认横线（GDD-06：右键按住拖拽定线列朝向与展开宽度为替代操作）。
- 证据：官方手册热键表通读无 stance/formation 键〔官方负发现〕；路A未查到任何队形功能描述。
- 来源：https://ftp.matrixgames.com/pub/BrokenArrow/BrokenArrowManualEBOOK.pdf

### B. 速度与底盘体系

**N10 速度数值体系：km/h 连续值、每单位多档** ✅两源一致（GDD-06 G3）
- 设定：MaxCrossCountrySpeed / MaxSpeedRoad / MaxSpeedReverse / MaxSpeedWater 四档独立数值 + Acceleration + TurnRate（brokenarrowstats.com 自 build 25235583 提取 395 单位）；非抽象档位。

**N11 轮式/履带/步兵道路加成差异** ✅两源一致（GDD-06 G3/G6）

- 证据：官方新闻数值（Chaborz/Tigr/M1288）〔官方〕+ 数据站逐页〔社区〕。
- 来源：https://steamstore-a.akamaihd.net/news/externalpost/steam_community_announcements/1842212951313855 ; https://brokenarrowstats.com/unit/humvee-47/ ; https://brokenarrowstats.com/unit/m2a3-bradley-16/

**N12 倒车速度数值（独立第三档）** ✅两源一致（GDD-06 G3/G5）

### D. 步兵机动与压制

**N22 冲刺（Z=Sprint）** 🔧GDD-06 G9 内部冲突获联网新证解决（详见 D5）
- 设定：短时间内移速翻倍（×2），需冷却后复用；**冲刺中完全禁射**（"Infantry cannot fire on the move if they are actively sprinting"）；官方点名用途=进攻冲锋或**打破压制撤回掩体**；同键对战斗机=加力（Afterburner）。适用范围：beta 期限突击步兵，**2024-10 Dev Diary #8 起加入所有步兵班**。
- 证据：官方手册（×2/充能）〔官方〕；beta 指南（禁射/限突击步兵）〔官方 beta〕；Dev Diary #8（全员化+步兵死于载具火力 −25% 配套）〔官方〕；冷却约 60 秒为社区玩家帖数值〔社区，低置信〕。
- 来源：https://ftp.matrixgames.com/pub/BrokenArrow/BrokenArrowManualEBOOK.pdf ; https://www.scribd.com/document/Broken-Arrow-Multiplayer-Beta-Guide ; https://www.matrixgames.com/news/broken-arrow-dev-diary-8-whats-changed/

**N23 姿态系统：无手动站/蹲/卧倒键；受压自动匍匐** ➕联网新证补充（GDD-06 未记）
- 设定：官方手册热键表无任何姿态切换键；步兵姿态为系统自动行为——受火力压制时自动匍匐（crawling）寻找掩体，降低射速但增加防护；周年更新因「防护收益压过射速惩罚导致受压班组反而占优」而调低受压减伤、调高受压射速惩罚。
- 证据：官方手册热键表通读（负发现）+ 周年更新 Designer's note 原文（2026-07-02）〔官方〕。
- 来源：https://ftp.matrixgames.com/pub/BrokenArrow/BrokenArrowManualEBOOK.pdf ; https://steamcommunity.com/app/1604270/announcements

**N24 压制两态（Shock/Panic）的量化影响** ✅两源一致（GDD-06 G8）
- 设定：步兵受压分 Shock 与 Panic 两档；压制对瞄准时间有乘法惩罚（某版本由 ×1→×2[shock]、×2→×3[panic] 加强）；周年/1.1.1 周期调整受压减伤与射速惩罚；**新增细节：运输车所受压制的 50% 转移给车内步兵**。
- 证据：官方更新公告〔官方〕。
- 来源：https://steamcommunity.com/app/1604270/announcements
- 对照：GDD-06 G8 记瞄准×2/×3 与抗性体系（同向）；50% 转移与「受压自动匍匐」为联网新证补充。

**N25 MMG 班组移动射击表现** ➕联网新证补充（GDD-06 未记）
- 设定：装备 MMG 的步兵班移动时并非真正边走边射——携枪成员「停下射击、再冲刺跟上大部队」；配套改动取消了该类班组的强制攻击移动默认行为。
- 证据：周年更新官方 Designer's note〔官方〕。
- 来源：https://steamcommunity.com/app/1604270/announcements

**N26 行进间开火** ⚠️部分分歧 D3（「100% 稳定度」社区口径 vs GDD-06「有精度惩罚」社区口径）
- 设定（两源一致部分）：炮塔单位行进开火是官方设计基线（1.0.10 设计者注移除 BMP-1 无炮塔停射的误导例外；GDD-06 G18）；例外=冲刺中的步兵与需架设的班组武器。
- 设定（分歧部分）：社区称「all units have 100% stabilization, don't need to stop to fire」（GameTruth/Reddit 摘要）；GDD-06 G18 记社区口径「行进开火有精度惩罚（数值未公开）」。
- 来源：https://www.gametruth.com/guides/broken-arrow-advanced-unit-tactics-and-combat/

**N27 运载步兵上下车** ✅两源一致（GDD-06 G20/G13）
- 设定：座位/载重双限制、多班可共车；下车有计时动画（patch 加 UI timer）；PTE 曾试「地面载具下车部署延迟」，1.1.1 正式移除（现行下车即时）；**新增细节：步兵可不下车在车内接受补给**；上车任一方可发起、可 Shift 排队（GDD-06 G20）。
- 证据：beta 手册 + 官方补丁记录〔官方〕。
- 来源：https://www.matrixgames.com/amazon/BrokenArrow/BrokenArrow_Basics.pdf ; https://store.steampowered.com/news/app/1604270/

**N28 载具被毁自动跳车与概率伤亡** ✅两源一致（GDD-06 G21）
- 设定：载具被毁时车内步兵自动跳车（auto-dismount）进场，伴随概率伤亡——15%→30%（2026-07 调），幸存者承受全额压力。

## 二、分歧清单（联网新证 vs GDD-06）

### D1 森林是否减速（最重大，挑战 GDD-06 MOV-GAP-09 结论）
- **联网新证**：开发者 FLX（Steel Balalaika）2022-06-09 Steam 讨论帖原话："Vehicles will move at their indicated maximum speed on roads, slower offroads, **even slower in forests**"〔官方，路B本会话直读帖子〕；Dev Diary #3："tracked to move faster off road, **especially in forests**"〔官方〕；社区指南总结履带在森林/崎岖地机动相对优于轮式〔社区〕。汇总员本次 WebSearch 复核 Dev Diary #3 摘要亦确认「off-road, especially in forests, vehicles move slower」方向。→ 开发口径：森林比普通越野**更慢**（倍率从未公布）。
- **GDD-06 旧档**（G6/G4）：「数据卡无逐地形速度表，**森林对速度不额外惩罚**（只影响隐蔽×2 与视线穿透衰减）」；依据=数据站只有路/野两档字段 + 官方博客「履带在森林不算恶劣地形」的解读 + Reddit 帖《Vehicles move way too fast through forests》抱怨现行森林不减车速（实测反证）。并据此 MOV-GAP-09 adopt「森林瓦片不注入速度 bp」。
- **矛盾实质**：开发口径/设计意图（森林更慢）vs 数据模型与玩家实测（无森林档、近似不减速）。同一 Dev Diary #3 句子两边都引了但解读相反（「履带在森林相对快」≠「森林不减速」——若森林对轮式惩罚更重，两说可同时成立）。
- **处置建议**：两条并存登记；GDD-06 G6 的「森林不减速」结论降级为「数据卡层面无森林档（属实）+社区实测近似不减速（低置信）」；MOV-GAP-09 的 adopt 建议改 **defer** 复核（若本作做森林减速 bp，断箭侧有开发口径支持；数值自定）。

### D2 牵引火炮存在性（GDD-06 误采，建议更正）
- **联网新证**：游戏无拖曳火炮/牵引机制——路C遍历官方单位志与 patch notes，全部火炮为自行/卡车底盘；Reddit 2024-03 帖《Is there a place in this game for towed artillery?》在**提议加入**（存在性反证）〔官方缺席证据+摘要〕。**汇总员本次会话定案**：WebFetch brokenarrowstats.com/arsenal/ 全库 395 单位，火炮名录中无 M777/M119/任何牵引炮。
- **GDD-06 旧档**（G10、未确证点 #3）：「牵引炮（M777/M119）：到位须先完成 deploy 动作才能开火，转移依赖牵引卡车〔社区〕；展开/收起秒数未取得」。
- **矛盾实质**：GDD-06 的 M777/M119 条目与全库单位数据直接矛盾。检索中仅见的「M777 vs. M109: Artillery Insights」为 Scribd 社区文档标题且属搜索 AI 概述转述（GDD-06 未确证点 #11 已确立「AI 概述不采信」纪律）——GDD-06 该句疑为把提议帖/AI 概述误记为实装。
- **处置建议**：GDD-06 G10 删除 M777/M119 表述（或改注「提议未实装」）；未确证点 #3 随之作废；GDD-06 引用的「Mortar teams and Towed artillery」Reddit 帖同理降级为提议讨论。

### D3 行进间开火精度口径（社区 vs 社区，低置信并存）

### D5 Sprint 适用范围：GDD-06 内部冲突获解决（更新而非推翻）
